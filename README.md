# 💫 About Me:
👋 Hi, I’m Nour Shady (@NourShady / Hackoro), an AI Engineer and Full-Stack Developer based in Egypt.<br><br>🎓 Currently pursuing a Bachelor's in Computer Science (Artificial Intelligence Specialization) at Mansoura University.<br>-🔭 I’m currently building (a hybrid RAG meeting intelligence platform) and an Egyptian Legal AI agent, alongside a bilingual JARVIS-inspired desktop HUD overlay.<br><br>🌱 I’m diving deeper into Applied AI, Vector Databases (Qdrant), LLM orchestration, and scalable backend architectures with FastAPI and Docker.<br><br>🛠️ My stack spans Python, FastAPI, TypeScript, React, React Native, Node.js, Electron, C#, PHP, and databases like MongoDB, MySQL, Qdrant, and Redis.<br><br>⚡ Beyond pure software, I love bridging the digital and physical worlds—building Arduino/ESP32 hardware prototypes, 3D-printed mechanical designs in SolidWorks/Blender, and running The Hub, a multidisciplinary software and creative fabrication studio.<br><br>📫 Reach me for freelance AI & software engineering collaborations via Upwork or right here on GitHub!
